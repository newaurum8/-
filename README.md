# Шесть AI-продуктов с рабочими демо в браузере

Витрина: `index.html` в корне. Каждый сайт лежит в `sites/<имя>/` и состоит из трёх файлов: `index.html`, `styles.css`, `app.js`. Ни сборки, ни зависимостей, ни бэкенда.

## Запуск

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080 (витрина) или http://localhost:8080/sites/kadr/ и т. д.

## Что общего

- Адаптивная вёрстка, проверена на 1400 и 390 px.
- Анимации появления, count-up, hover-эффекты, `prefers-reduced-motion` учитывается.
- Шрифты с кириллицей через Google Fonts: Unbounded, Manrope, Yeseva One, Onest, Geologica, JetBrains Mono, Cormorant Garamond, Golos Text, Playfair Display, Jost, Inter Tight.
- Все «ИИ-функции» в демо работают на правилах и процедурной графике, чтобы сайт был самодостаточным. Для продакшена каждое демо подключается к модели через API, точки подключения отмечены в коде (`analyze`, `render`, `applyStyle`, `buildScenes`, `makeLogo`).

## Папки `reports/` и `research_notes/`

Исследовательские заметки о скилах и инструментах Claude для фронтенда, SVG, видео и 3D. К сайтам не относятся.
