## 1. Blender MCP с Claude Code: установка (аддон + сервер), инструменты, ограничения и безопасность. Плюс прочие DCC (Maya, Cinema 4D, Houdini, 3ds Max)

### Takeaway
В 2026 году для Blender есть два основных MCP, и подключать их надо по-разному.
- Community-вариант: `ahujasid/mcp-for-blender` (бывший `blender-mcp`, ~31,7k★, активен). Подключается одной командой `claude mcp add blender uvx mcp-for-blender` плюс `uvx mcp-for-blender install-addon`. Даёт 9 инструментов, среди них произвольный Python, мультиракурсные скриншоты для самопроверки, Poly Haven, Sketchfab, Poly Pizza, Tripo, Rodin, Hunyuan3D и Meshy.
- Официальный вариант: Blender Lab MCP (`projects.blender.org/lab/blender_mcp`, v1.0.x, требует Blender 5.1+). Он сознательно минимальный, но в него вшиты справочник bpy API и выдержки из мануала. Для Claude Code его ставят из исходников через `.mcp.json`.

В обоих случаях Claude получает неаутентифицированный TCP-сокет и выполнение произвольного Python в живом Blender. Перед сессией сохраняйте файл и работайте на копии.

Из прочих DCC: для 3ds Max и Houdini есть зрелые, активно развиваемые community-MCP. Для Cinema 4D и Maya есть только небольшие community-проекты; официального Autodesk-MCP для Maya не найдено.

### Cited Findings

**A. MCP for Blender (ex-`blender-mcp`). Автор Siddharth Ahuja, community, «not made by Blender»**
- Репозиторий переименован в `ahujasid/mcp-for-blender`, PyPI-пакет теперь `mcp-for-blender`. Старый `uvx blender-mcp` по-прежнему работает, конфиг менять не обязательно. Описание репозитория: «Community plugin to control Blender 3D with any LLM… Not affiliated with the official Blender Foundation». Метрики: 31 652★, 2 972 форка, 52 open issues, MIT, push 2026-10-18 — [GitHub](https://github.com/ahujasid/mcp-for-blender)
- Автоматическая установка: `curl -LsSf https://www.mcp-for-blender.com/install.sh | sh` (macOS/Linux) либо `uvx mcp-for-blender setup`. Скрипт находит Claude Code, Claude Desktop, Codex, Cursor и VS Code, добавляет запись `blender` (с `.bak` каждого изменённого конфига), ставит и включает аддон — [README](https://github.com/ahujasid/mcp-for-blender#quickstart)
- Ручная установка для Claude Code — [README](https://github.com/ahujasid/mcp-for-blender#quickstart):
  - сервер: `claude mcp add blender uvx mcp-for-blender`;
  - аддон: `uvx mcp-for-blender install-addon`;
  - в Blender: Edit → Preferences → Add-ons → включить **Interface: MCP for Blender**;
  - в 3D-viewport нажать `N`, открыть вкладку **MCP for Blender** и нажать **Start MCP Server**.
- Требования: Blender 3.0+, Python 3.10+ и `uv`, поставленный официальным установщиком. Через `pip install uv` ставить нельзя: команда `uvx` может не появиться. При конфликтах с conda или pyenv README советует `"args": ["--python","3.11","mcp-for-blender"]` и `UV_PYTHON_PREFERENCE=only-managed`. Если прошлая неудачная попытка «залипла», чистить кеш: `uv cache clean mcp-for-blender blender-mcp && uvx --refresh mcp-for-blender` — [README](https://github.com/ahujasid/mcp-for-blender#prerequisites)
- Обновление: `uvx mcp-for-blender@latest update` обновляет сервер и все копии аддона. После него нужно перезапустить MCP-клиент и Blender — [README](https://github.com/ahujasid/mcp-for-blender#upgrading-existing-users)
- Девять инструментов — [README → Capabilities](https://github.com/ahujasid/mcp-for-blender#capabilities):
  - `execute_blender_code`: Python в живом Blender;
  - `look`: вид из `viewport`, `camera`, `angles` (автокадрированный мультиракурсный лист), `frames` (анимационная лента) в режимах `solid`, `material`, `rendered`, `wireframe` или `xray`, а также показ рендера или файла;
  - `get_scene_info`: компактная сводка, по строке на объект, с детализацией через `root` и `query`;
  - `generate_3d`: Tripo, Hunyuan3D, Hyper3D Rodin или Meshy;
  - `search_assets` и `import_asset`: Poly Haven, Sketchfab, Poly Pizza;
  - `get_addon_status`;
  - `disable_telemetry` и `record_trajectory_feedback`.
- Источники ассетов — [README](https://github.com/ahujasid/mcp-for-blender#capabilities):
  - Poly Haven: около 2 400 CC0-ассетов, ключ не нужен. Импорт идёт из `.blend`, потому что в glTF, FBX и USD теряются детали материалов;
  - Poly Pizza: около 10 600 low-poly моделей, бесплатный ключ. Примерно 69 % каталога под CC-BY, атрибуция пишется в custom property `polypizza_attribution`;
  - Meshy: нужен ключ платного плана;
  - Hunyuan3D: через Tencent Cloud, отдельный тумблер для международного аккаунта.
- Ключи сохраняются в Preferences аддона или в env-переменных: `BLENDERMCP_SKETCHFAB_API_KEY`, `BLENDERMCP_HYPER3D_API_KEY`, `BLENDERMCP_HUNYUAN3D_SECRET_ID`, `BLENDERMCP_HUNYUAN3D_SECRET_KEY`, `BLENDERMCP_MESHY_API_KEY`, `BLENDERMCP_POLYPIZZA_API_KEY`. Платный «Premium» даёт генерацию без собственных ключей — [README](https://github.com/ahujasid/mcp-for-blender#persistent-api-credentials)
- Безопасность — [README](https://github.com/ahujasid/mcp-for-blender#limitations--security-considerations):
  - официальное предупреждение: «`execute_blender_code` allows running arbitrary Python code… **ALWAYS save your work before using it**»;
  - сокет аддона «has no authentication or encryption», поэтому его следует держать на `localhost`, а для удалённой машины использовать SSH-туннель;
  - `BLENDER_MCP_SAFE_MODE=1` проверяет скрипты перед запуском и блокирует прямой файловый I/O, запуск процессов, сеть и «персистентный» код. Моделирование, рендер и import/export при этом работают.
- Прочие настройки:
  - порт по умолчанию `localhost:9876` (`BLENDER_HOST`, `BLENDER_PORT`); для нескольких Blender одновременно запускать `uvx mcp-for-blender --port 9877` и выставлять тот же порт в аддоне;
  - запускать только один экземпляр MCP-сервера;
  - «Do not run the `uvx` command in the terminal»: сервер стартует сам MCP-клиент.

  Источник: [README](https://github.com/ahujasid/mcp-for-blender#environment-variables)
- Ограничения: сложные операции стоит дробить на мелкие шаги, при таймаутах упрощать запрос. Скачивание с Poly Haven идёт в главном потоке Blender, и UI замирает; лучше просить разрешение 1k–2k — [README → Troubleshooting](https://github.com/ahujasid/mcp-for-blender#troubleshooting)
- Телеметрия: по умолчанию собирается минимальная анонимная статистика (install ID, имя инструмента, успех, длительность, версии, ОС). Промпты, код и скриншоты собираются только после явного opt-in. Полностью отключается через `DISABLE_TELEMETRY=true` в `env` MCP-конфига — [README → Telemetry](https://github.com/ahujasid/mcp-for-blender#telemetry-control)
- Примеры промптов из README:
  - «Create a low poly scene in a dungeon, with a dragon guarding a pot of gold»;
  - «Create a beach vibe using HDRIs, textures, and models… from Poly Haven»;
  - «Get information about the current scene, and make a threejs sketch from it»;
  - «Point the camera at the scene, and make it isometric».

  Источник: [README → Example Commands](https://github.com/ahujasid/mcp-for-blender#example-commands)

**B. Официальный Blender Lab MCP Server. Сопровождает Blender Lab**
- Ссылки: документация [blender.org/lab/mcp-server](https://www.blender.org/lab/mcp-server/), код [projects.blender.org/lab/blender_mcp](https://projects.blender.org/lab/blender_mcp), wiki [Setup](https://projects.blender.org/lab/blender_mcp/wiki/Setup). Официальные страницы утверждают, что в Blender нет встроенной связи с LLM; нужны аддон, LLM-клиент и MCP-сервер. Аддон ставится drag-and-drop в два шага: сначала добавить репозиторий Blender Lab, затем сам аддон (так приходят уведомления об обновлениях). Для клиентов с поддержкой `.mcpb` есть готовый пакет на странице релизов — [поисковая выдержка с blender.org / projects.blender.org](https://www.blender.org/lab/mcp-server/)
- Манифест аддона в GitHub-зеркале (`id = "mcp"`, `version = "1.0.0"`, `maintainer = "Blender Lab"`, `blender_version_min = "5.1.0"`, GPL-3.0-or-later, permission `network = "Runs a local TCP socket server…"`) — [зеркало SJJ-universe/blender-lab-mcp](https://github.com/SJJ-universe/blender-lab-mcp) (неофициальное зеркало, коммит 2026-05-05)
- Архитектура: `MCP Client ⇐ MCP/stdio ⇒ blender-mcp ⇐ TCP socket ⇒ Blender Add-on`. Проект описан как «deliberately small, maintainable». Сервер несёт с собой Blender Python API reference и выдержки из мануала в RST и `prompts.yml` — [readme зеркала](https://github.com/SJJ-universe/blender-lab-mcp)
- Инструменты (около 24) — [readme зеркала](https://github.com/SJJ-universe/blender-lab-mcp):
  - выполнение кода: `execute_blender_code`, а также `execute_blender_code_for_cli` для фонового Blender без GUI;
  - сводки по файлу: `get_blendfile_summary_*` (datablocks, missing files, linked libraries, path info, usage guess), каждая с `_for_cli`-вариантом;
  - объекты: `get_objects_summary`, `get_object_detail_summary`;
  - документация: `get_python_api_docs`, `search_api_docs`, `search_manual_docs`;
  - скриншоты: `get_screenshot_of_area_as_image`, `get_screenshot_of_window_as_image`, `get_screenshot_of_window_as_json`;
  - навигация: `jump_to_*`;
  - рендер: `render_thumbnail_to_path`, `render_viewport_to_path`.
- «Песочница» `weak_sandbox.py` прямо заявлена как ненастоящая: «this isn't really a sandbox… If the LLM (or its user) is motivated these can be worked around. This is more of a slap on the wrist» — [исходник в зеркале](https://github.com/SJJ-universe/blender-lab-mcp/blob/main/addon/blender_mcp_addon/weak_sandbox.py)
- Хронология релизов: v0.1.0 (pre-release, март 2026) → v1.0.0 (27.04.2026) → v1.0.3 (11.09.2026) — [StraySpark, вторичный и коммерческий источник](https://www.strayspark.studio/blog/official-blender-mcp-server-comparison-2026). Сам репозиторий проверить не удалось.
- Документация проекта предупреждает, что сгенерированный Python может изменить или удалить данные проекта, и советует работать на копии файла — [StraySpark (вторичный)](https://www.strayspark.studio/blog/official-blender-mcp-server-comparison-2026)
- Claude Code (community-гайды; официальной CLI-команды нет):
  - клонировать репозиторий и прописать в `.mcp.json`: `"command": "uv", "args": ["--directory", "/abs/path/blender_mcp/mcp", "run", "blender-mcp"]`. В Claude Code нет поля `cwd`, поэтому `--directory` передаётся в `uv` и должен стоять до `run`; путь абсолютный, `$HOME` в `.mcp.json` не раскрывается;
  - чтобы не подтверждать каждый вызов, `mcp__blender__execute_blender_code` можно заранее разрешить в `.claude/settings.json`.

  Источники: [issue #23 «Tutorial… with ClaudeCode CLI»](https://projects.blender.org/lab/blender_mcp/issues/23), [Jan-Hendrik Müller](https://jan-hendrik-mueller.de/blog/blender-mcp-config-codex-claude-code-opencode/), [nonuplet/blender-mcp-tools](https://github.com/nonuplet/blender-mcp-tools)
- Известная проблема: Claude Desktop extension не ставится на Windows (ошибка egg_base, сервер не стартует) — [issue #24](https://projects.blender.org/lab/blender_mcp/issues/24)
- Контекст: 28.04.2026 Anthropic запустила «Claude for Creative Work» с девятью коннекторами, среди них Blender, Adobe, Autodesk Fusion, SketchUp и Ableton. Тогда же Anthropic стала Corporate Patron Blender Development Fund (от €240 000 в год) — [RedShark News](https://www.redsharknews.com/anthropic-claude-creative-connectors-adobe-blender-autodesk), [NYU Shanghai RITS](https://rits.shanghai.nyu.edu/ai/anthropic-plugs-claude-into-adobe-blender-and-ableton-with-nine-new-connectors/)

### Inferences
- Для Claude Code практичнее community MCP for Blender: одна команда, мультиракурсный `look` для самопроверки и встроенные ассеты и генерация. Официальный Blender Lab лучше там, где важны точный bpy API (встроенная документация), headless-режим (`*_for_cli`) и лицензия и происхождение кода (GPL, Blender Lab). Ставить оба под одним именем `blender` нельзя: оба по умолчанию используют TCP-сокет, поэтому имена в MCP-конфиге и порты нужно развести.
- Рабочий цикл самопроверки:
  1. `get_scene_info`;
  2. маленький `execute_blender_code`;
  3. `look(view="angles")`;
  4. правка.

  Для больших сцен запрашивать сводку только по нужным полям: ответ MCP-инструмента в Claude Code ограничен примерно 25k токенов, предупреждение появляется с 10k, лимит поднимается через `MAX_MCP_OUTPUT_TOKENS`. Цифры подтверждены только вторичными источниками: [копия документации Claude Code MCP](https://glama.ai/mcp/servers/@marc-shade/universal-ai-chat/blob/3d65574a888705c4f462b8331a186f0721e0e115/docs/claude-code-mcp-docs.md), [Xpoz help](https://help.xpoz.ai/en/articles/12681842-claude-code-mcp-tool-exceeds-maximum-allowed-tokens-25000).
- Безопасность в Claude Code. Не стоит заранее разрешать `execute_blender_code` глобально. Разрешать его лучше на уровне проекта, вместе с `BLENDER_MCP_SAFE_MODE=1` и предварительно сохранённым `.blend`. Ассеты и генераторы включать только нужные.

### Gaps

- Не найдено официальное число звёзд и коммитов Blender Lab: Gitea закрыт прокси.
- Нет статистики того, насколько надёжно модели работают со сценами в тысячи объектов. В README есть только общее «break down into smaller steps».

## 2. Unity / Unreal / Godot: самые зрелые MCP и официальные решения

### Takeaway
Официальные MCP теперь есть у Unity (в пакете AI Assistant, Unity 6+, нужна подписка Unity AI) и у Epic (экспериментальный плагин Unreal MCP в UE 5.8). Оба молодые.

Самые зрелые и популярные варианты по-прежнему community:
- Unity: CoplayDev «MCP for Unity» (15,1k★, v10.3.0 от 2026-10-04); IvanMurzak «AI Game Developer» (4,5k★, CLI и скилы);
- Unreal: ChiR24 `Unreal_mcp` (UE 5.0–5.8, активен). Популярный chongdashu по сути заброшен с апреля 2025;
- Godot: Coding-Solo `godot-mcp` (6,2k★, headless-запуск и отладка) и `hi-godot/godot-ai` (3,1k★, живой редактор, от авторов MCP for Unity).

Официального Godot MCP не найдено.

### Cited Findings

**Unity**
- **MCP for Unity (CoplayDev/unity-mcp)**, community, спонсор и мейнтейнер Aura, «not affiliated with Unity Technologies» — [GitHub](https://github.com/CoplayDev/unity-mcp):
  - метрики: 15 149★, 1 689 форков, последний коммит 2026-10-19 (ветка `beta`), релизы v10.3.0 (2026-10-04), v10.2.0 (2026-09-01);
  - требования: Unity 2021.3 LTS → 6.x, Python 3.10+ через `uv`;
  - установка: Package Manager → Add from git URL `https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#main` (или `openupm add com.coplaydev.unity-mcp`), затем `Window → MCP for Unity → Configure All Detected Clients`.
- Транспорты MCP for Unity — [docs/getting-started/install](https://github.com/CoplayDev/unity-mcp/blob/beta/website/docs/getting-started/install.md), [troubleshooting](https://github.com/CoplayDev/unity-mcp/blob/beta/website/docs/guides/troubleshooting.md):
  - HTTP по умолчанию: `http://localhost:8080/mcp`;
  - stdio: `uvx --from mcpforunityserver mcp-for-unity --transport stdio` (Claude Desktop умеет только stdio);
  - пример для Claude Code из troubleshooting: `claude mcp add --transport http UnityMCP http://<host>:8090/mcp`;
  - после смены транспорта Claude Code надо перезапустить.
- Инструменты MCP for Unity — [v10 migration notes](https://github.com/CoplayDev/unity-mcp/blob/beta/website/docs/migrations/v10.md), [generate_model](https://github.com/CoplayDev/unity-mcp/blob/beta/website/docs/reference/tools/asset_gen/generate_model.md):

## 4. AI-генерация 3D: какие сервисы имеют рабочие MCP для Claude Code

### Takeaway
Для Claude Code реально работают три MCP:
- официальный hosted **Hyper3D Rodin MCP** (`https://api.hyper3d.com/api/mcp`, вход через браузер, Claude Code в документации);

Официальный `tripo-mcp` в alpha, не обновлялся с апреля 2025 и требует Blender-аддон Tripo. Официального Tencent Hunyuan3D MCP не найдено. Sketchfab, Poly Haven и Poly Pizza доступны через Blender MCP.

### Inferences
- Самый простой путь в Claude Code — Hyper3D Rodin hosted MCP: нет локального сервера, нет ключей в конфиге, оплата идёт на workspace. Вероятная команда `claude mcp add --transport http hyper3d-rodin https://api.hyper3d.com/api/mcp`, затем авторизация через `/mcp`. Команда выведена из описания, а не процитирована.
- Если модель нужна сразу в сцене, лучше генерировать через DCC-MCP (Blender `generate_3d`, Unity `generate_model`). Тогда импорт, масштаб и материалы можно сразу проверить скриншотом.
- Для 3D-печати Meshy MCP сейчас единственный найденный вариант с проверкой и починкой printability и мультиколорным 3MF в одном сервере.

### Gaps
- Точная команда Claude Code со страницы hyper3d.ai/features/mcp не получена (страница не открывалась).
- Не проверено, есть ли у Tripo новый официальный hosted MCP после 2025 года. Найден только неофициальный Codex-плагин [GrinZero/tripo-studio-plugin](https://github.com/GrinZero/tripo-studio-plugin).
- Нет независимых сравнений качества моделей Rodin, Meshy, Tripo и Hunyuan3D по состоянию на октябрь 2026.

## 5. CAD / параметрика / 3D-печать: OpenSCAD, CadQuery / build123d, FreeCAD, Fusion 360

### Takeaway
Сильная сторона Claude в CAD — код. Лучше всего работают MCP, которые исполняют сгенерированный CAD-скрипт, рендерят превью и измеряют геометрию:
- `pzfreo/build123d-mcp`: на CADGenBench поднял score с 0,360 до 0,457 и validity с 88 % до 100 %;
- `RobertCoop/openscad-mcp`: рендер с масштабом и проверка пересечений, `claude mcp add openscad --transport stdio -- uvx openscad-mcp`;
- `jdilla1277/agentcad`: CLI + MCP + skill, build123d по умолчанию;
- `neka-nat/freecad-mcp`: 3k★, живой FreeCAD, скриншоты вида, headless-скрипты, FEM на CalculiX.

Для Fusion 360 есть официальный коннектор Autodesk, ориентированный на Claude Desktop, и community-сервер `faust-machines/fusion360-mcp-server` с командой для Claude Code. Отдельные CadQuery-MCP малы. CadQuery удобнее использовать как compat-режим agentcad.

### Inferences
- Самые надёжные под code-first сильные стороны Claude — build123d-mcp и agentcad: Python, B-rep, STEP. Выигрыш на бенчмарке появляется за счёт пошаговой сборки с измерениями и рендером вместо «слепого» скрипта.
- OpenSCAD-MCP хорош для простых печатных деталей. FreeCAD-MCP нужен, когда важны живой документ, FEM или библиотека деталей.
- Порядок проверки, общий для всех:
  1. рендер видов (iso, front, top);
  2. измерение габаритов и объёма;
  3. проверка watertight и манифолдности;
  4. экспорт.
- Все CAD-MCP исполняют код без песочницы: OpenSCAD `import`/`include`, `execute_code` во FreeCAD и Fusion. В Claude Code их стоит держать на уровне проекта и не включать auto-approve глобально.
- build123d-mcp советует `~/.claude/mcp.json` для глобальной установки, но в Claude Code пользовательский scope обычно задаётся через `claude mcp add --scope user …` и хранится в `~/.claude.json`. Надёжнее вариант `claude mcp add --scope user build123d-mcp -- uv tool run --python 3.12 build123d-mcp@latest`. Это вывод: в этой сессии по документации Claude Code не перепроверено.

### Gaps
- Официальная документация Autodesk по локальному Fusion MCP (порт 27182, совместимость с Claude Code) не открывалась. Данные из одного вторичного блога.
- Не найден Onshape MCP и официальные MCP для SolidWorks и SketchUp. SketchUp упоминается среди коннекторов Anthropic от 28.04.2026, но детали не изучались.
- Нет бенчмарков, кроме CADGenBench, сравнивающих OpenSCAD, CadQuery, build123d и FreeCAD именно с Claude.
