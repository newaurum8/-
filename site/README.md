# Kadr — генератор продающих фото, карточек и видео

Статический сайт-продукт: лендинг + рабочая студия в браузере. Без сборки и зависимостей.

## Запуск

```bash
cd site && python3 -m http.server 8080
```

Откройте http://localhost:8080.

## Что умеет студия

- 6 форматов под площадки: Wildberries, Ozon, Instagram, Reels, Avito, Telegram.
- 6 визуальных стилей, бесконечные варианты композиции (кнопка «Новый вариант»).
- Загрузка собственного фото товара, иначе рисуется силуэт.
- Экспорт PNG в нативном разрешении.
- Экспорт 6-секундного видео (MP4 в Safari/Chrome с поддержкой, иначе WebM) через MediaRecorder.

## Бизнес-модель

| Тариф | Цена | Себестоимость при полной выработке | Маржа |
|---|---|---|---|
| Старт | 0 ₽ | ~40 ₽ | лид-магнит |
| Селлер | 1 490 ₽/мес | ~1 140 ₽ при 300 карточек + 60 видео (реально 20–30% выработки) | 70%+ |
| Агентство | 6 900 ₽/мес | ~4 500 ₽ при 500 видео | 35%+, upsell API |
