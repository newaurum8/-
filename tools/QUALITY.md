# Контракт качества фронтенда для сайтов в `sites/<slug>/`

Каждый сайт — три файла: `index.html`, `styles.css`, `app.js`. Без сборки, без зависимостей, без бэкенда, без внешних JS-библиотек. Шрифты только через Google Fonts (`display=swap`), только гарнитуры с кириллицей:
Unbounded, Manrope, Onest, Golos Text, Geologica, Inter Tight, Inter, Montserrat, Rubik, Raleway, Jost, Exo 2, Oswald, Russo One, Comfortaa, Nunito, Roboto Slab, Playfair Display, Cormorant Garamond, Prata, Lora, Merriweather, Bitter, Piazzolla, Spectral, Literata, EB Garamond, Vollkorn, Yeseva One, Oranienbaum, Caveat, Marck Script, Amatic SC, JetBrains Mono, IBM Plex Mono, Fira Code, Press Start 2P, Tektur, Alumni Sans.

## Обязательные свойства

1. **Уникальная визуальная система.** Свои токены цвета в `:root`, своя пара шрифтов (дисплейный + текстовый), свой ритм отступов, свои формы (радиусы, границы, тени). Ни один сайт не должен выглядеть как другой и как «шаблон SaaS». Запрещены стоковые картинки и эмодзи как иллюстрации: вся графика рисуется кодом (SVG, canvas, CSS).
2. **Живой hero.** В первом экране есть настоящий анимированный или интерактивный центр (canvas-сцена, SVG-механизм, живая симуляция, генератор), а не статичная картинка.
3. **Рабочее демо ценности продукта.** Главная функция продукта работает в браузере на правилах, процедурной графике, локальной базе данных или localStorage. Пользователь вводит данные и получает результат. Все кнопки что-то делают. Пустых заглушек «скоро» нет.
4. **Движение.** Появление блоков при прокрутке, count-up чисел, hover- и focus-эффекты, плавные переходы состояний. Всё уважает `prefers-reduced-motion`. Для появления используйте класс `.reveal` + `.in` (скрипт проверки принудительно добавляет `.in` перед скриншотом).
5. **Адаптив.** Корректно от 360 до 1440 px, без горизонтального скролла на 390 px, навигация сворачивается на мобильном, размер тач-целей не меньше 40 px, текст не мельче 14 px.
6. **Доступность.** Семантические `header/main/section/footer`, у каждого поля есть `<label>` или `aria-label`, у переключателей `aria-pressed`, видимый `:focus-visible`, контраст основного текста не ниже 4.5:1, у `<canvas>` и декоративной графики `aria-hidden` или описание.
7. **Чистота.** Ноль ошибок в консоли, ноль упавших запросов (кроме шрифтов), валидный HTML, `lang="ru"`, `<title>`, `<meta name="description">`, inline SVG favicon, `<html>` с `scroll-behavior: smooth`.
8. **Текст.** Живой русский язык, конкретика вместо общих слов, цифры там, где они продают. Структура лендинга: nav → hero → доказательства → демо → как работает → примеры/галерея → тарифы с юнит-экономикой → FAQ → CTA → footer. Разделы можно переставлять под продукт, но демо и тарифы обязательны.
9. **Размер.** `app.js` не больше 40 КБ, `styles.css` не больше 25 КБ. Код читаемый, с короткими комментариями по разделам.

## Проверка

Сервер уже запущен: `http://localhost:8080` отдаёт корень репозитория. Проверка:

```bash
node tools/check.js /sites/<slug>/ /tmp/claude-0/-home-user--/8acb284c-e9a4-50a2-83e6-c8635565fedb/scratchpad/<slug> '[{"scroll":"#demo"},{"click":"#run"},{"wait":1500},{"shot":"demo"}]'
```

Скрипт печатает JSON: ошибки, ширину прокрутки, мелкие тач-цели, поля без подписи, пути к скриншотам `desktop.png` и `mobile.png`. Скриншоты нужно открыть и посмотреть глазами: наложения, обрезанный текст, невидимый текст на фоне, пустые секции, уродливые пропорции. Критерий готовности: `errors: []`, `mobileOverflow: false`, скриншоты без визуальных дефектов, демо на скриншоте показывает результат.

## Эталоны

`sites/takt` (кино, процедурные сцены), `sites/znak` (швейцарская сетка, генератор SVG), `sites/tarelka` (светлый, иллюстративный). Изучите один из них для понимания планки, но не копируйте дизайн.
