# Claude Code рисует лучше, когда видит свой результат

К октябрю 2026 года для фронтенда, SVG, видео и 3D лучше всего работает небольшой набор инструментов, почти все они от самих вендоров. Сильные варианты устроены одинаково: Claude рендерит свою работу, смотрит на PNG или скриншот и исправляет. **Фронтенд:** `frontend-design` от Anthropic, Context7, скил shadcn, один браузерный инструмент (Playwright CLI или MCP, для производительности добавить Chrome DevTools MCP) и плагин Figma. **SVG:** официального скила нет. Качество дают цикл «resvg/rsvg-convert → PNG → правка», SVGO v4 и узкие инструменты: logo-design-skill, официальный плагин draw.io, claude-mermaid, Excalidraw-скилы, официальные gsap-skills. **Видео:** Remotion заменил свой MCP официальными Agent Skills, а HeyGen HyperFrames стал бесплатной альтернативой под Apache-2.0. Монтаж надёжнее делать через Bash с ffmpeg и auto-editor, чем через универсальные FFmpeg-MCP. Самый зрелый мост к монтажной программе — DaVinci Resolve MCP, но он работает только с Resolve Studio. **3D:** MCP for Blender (бывший blender-mcp), threejs-skills под r186, CoplayDev MCP for Unity, официальный экспериментальный Unreal MCP в UE 5.8, а для CAD — build123d- и OpenSCAD-MCP. Ставить всё это лучше через `/plugin` из официального маркетплейса `claude-plugins-official` или из репозиториев вендоров. Сторонние скилы проверяйте как чужой код: аудит Snyk нашёл критические проблемы у 13,4 % скилов в открытых реестрах, а плагины и MCP-серверы работают вне песочницы Claude Code с правами вашего пользователя.

## Скил хранит знание, MCP даёт доступ к инструментам, плагин всё упаковывает

Скил в Claude Code — это папка с файлом `SKILL.md` (YAML-frontmatter и инструкции) и необязательными `scripts/`, `references/` и `assets/`. Формат следует открытому стандарту Agent Skills, который Anthropic опубликовала 18 декабря 2025 года, поэтому те же скилы понимают Codex, Gemini CLI, Cursor и Copilot ([Anthropic Engineering](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills); [спецификация Agent Skills](https://github.com/agentskills/agentskills/blob/main/docs/specification.mdx)). В контексте постоянно лежат только имя и описание, **около 100 токенов на скил**. Тело загружается при вызове, а от скриптов в контекст попадает только их вывод ([Claude Platform: Agent Skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)). MCP-сервер подключает живой внешний инструмент: браузер, файл Figma, сцену Blender, таймлайн Resolve. Плагин упаковывает скилы, хуки, субагентов и MCP-серверы в одну устанавливаемую единицу. Хук нужен для правил, которые должны срабатывать всегда, без решения модели ([Extend Claude Code](https://code.claude.com/docs/en/features-overview)). Пользовательские slash-команды объединены со скилами: `.claude/commands/deploy.md` и `.claude/skills/deploy/SKILL.md` создают одну и ту же `/deploy`, а при совпадении имён побеждает скил ([Claude Code: Skills](https://code.claude.com/docs/en/skills)). Описанные ниже возможности соответствуют Claude Code **v2.1.303 от 18 октября 2026 года**. У многих функций есть минимальная версия, поэтому если команда не срабатывает, сначала выполните `claude update` ([Changelog](https://code.claude.com/docs/en/changelog)).

Официальный маркетплейс `claude-plugins-official` (репозиторий `anthropics/claude-plugins-official`, **315 плагинов** на момент проверки) подключается автоматически при первом интерактивном запуске. Команда `/plugin install <plugin>@claude-plugins-official` не ставит плагин сразу. Сначала открывается панель со списком того, что будет установлено, а у официальных плагинов там же есть оценка **Context cost** в двух вариантах: «Every turn» и «When invoked». После этого выбирается scope: user, project или local ([Install plugins](https://code.claude.com/docs/en/plugins/install); [marketplace.json](https://github.com/anthropics/claude-plugins-official/blob/main/.claude-plugin/marketplace.json)). Сторонний маркетплейс регистрируется один раз командой `/plugin marketplace add <owner>/<repo>`. Имя после `@` в команде установки берётся из поля `name` его `marketplace.json` и часто не совпадает с именем репозитория. Например, `anthropics/skills` регистрируется как `anthropic-agent-skills` ([anthropics/skills marketplace.json](https://github.com/anthropics/skills/blob/main/.claude-plugin/marketplace.json)). **Самая частая ошибка из старых туториалов** — команда `/plugin marketplace add anthropics/claude-code`. Она добавляет демо-маркетплейс `claude-code-plugins`, а не официальный, и в итоге у вас оказываются вторые копии плагинов вроде `code-review` ([Anthropic's marketplaces](https://code.claude.com/docs/en/plugins/anthropic-marketplaces)). Команды `/plugin add /path/to/skill-directory` из списка travisvn/awesome-claude-skills в текущей документации нет. Вместо неё используют `--plugin-dir <dir>`, `/plugin marketplace add ./path` или просто копируют папку в `~/.claude/skills/` ([travisvn/awesome-claude-skills](https://github.com/travisvn/awesome-claude-skills); [Install plugins](https://code.claude.com/docs/en/plugins/install)).

| Что сделать | Команда |
|---|---|
| Подключить маркетплейс, с пиннингом тега или ветки | `/plugin marketplace add owner/repo` или `owner/repo#v1.2.0` |
| Поставить плагин в сессии | `/plugin install name@marketplace`, затем `/reload-plugins` |
| Поставить из терминала или скрипта | `claude plugin install name@marketplace --scope project` |
| Посмотреть состав плагина и сколько токенов он занимает постоянно | `claude plugin details name` |
| Поставить скил из любого GitHub-репозитория | `npx skills add owner/repo -a claude-code` (`-g` глобально, `--skill name` выборочно, `-l` список) |
| Положить скил вручную | `~/.claude/skills/<name>/SKILL.md` (личный) или `.claude/skills/<name>/SKILL.md` (проектный) |
| Подключить удалённый MCP | `claude mcp add --transport http name URL`, затем `/mcp` для OAuth |
| Подключить локальный MCP | `claude mcp add --scope user name -- command args` |
| Посмотреть, сколько расширения занимают в контексте | `/skill-doctor`, `/context`, `/doctor` |

Scope user записывается в `~/.claude/settings.json`, project — в `.claude/settings.json` (этот файл коммитится), local — в `.claude/settings.local.json`. Для команд есть важная тонкость: закоммиченный project-scope включает плагин у коллег, но не скачивает его. Каждому нужно один раз выполнить `claude plugin install <name>@<marketplace> --scope project` ([Install plugins](https://code.claude.com/docs/en/plugins/install)). Чтобы раздать команде целый набор, в `.claude/settings.json` прописывают `extraKnownMarketplaces` и `enabledPlugins`. Эти записи начинают действовать только после того, как пользователь подтвердит доверие к папке ([Settings reference](https://code.claude.com/docs/en/settings-reference)). Облачные сессии claude.ai/code не читают `~/.claude/skills/` и не загружают локально установленные плагины. Всё, что нужно в облаке, коммитьте как проектные скилы или включайте в аккаунте claude.ai ([Skills](https://code.claude.com/docs/en/skills); [Install plugins](https://code.claude.com/docs/en/plugins/install)).

CLI `npx skills` от Vercel (skills.sh) ставит скилы в Claude Code и ещё в 75 агентов ([vercel-labs/skills](https://github.com/vercel-labs/skills)). Подвох в путях. Claude Code читает только `.claude/skills/` и `~/.claude/skills/`, а большинство других агентов читают `.agents/skills/`. Скил, который попал только в `.agents/skills/`, Claude Code не увидит, поэтому добавляйте флаг `-a claude-code`. Например, собственный CLI Remotion кладёт скилы в `.agents/skills` и делает на эту папку симлинк `.claude/skills` ([Remotion: npx remotion skills](https://www.remotion.dev/docs/cli/skills)). Реестр skills.sh может отставать от `main` на несколько часов. Поэтому HyperFrames советует агентам обновляться своей командой `npx hyperframes skills update` ([HyperFrames README](https://github.com/heygen-com/hyperframes)). Если скил должен работать ещё и в claude.ai или через API, оставьте во frontmatter только шесть полей спецификации: `name`, `description`, `license`, `compatibility`, `metadata`, `allowed-tools`. Поля, которые есть только в Claude Code, например `argument-hint`, ломают загрузку с ошибкой `Unexpected key(s) in SKILL.md frontmatter` ([Skills](https://code.claude.com/docs/en/skills)).

Удалённые MCP-серверы подключаются командой `claude mcp add --transport http <name> <url>`. Локальные stdio-серверы — командой `claude mcp add [опции] <name> -- <command> [args...]`, где всё после `--` передаётся серверу без изменений. Транспорт SSE объявлен устаревшим ([Claude Code: MCP](https://code.claude.com/docs/en/mcp)). Scope `local` (он по умолчанию) хранится в `~/.claude.json` и действует только в текущем проекте. Scope `project` пишется в `.mcp.json` и расходится через git, поэтому секреты выносите в переменные `${VAR}`. Scope `user` действует во всех проектах. **Tool search включён по умолчанию**: при старте загружаются только имена инструментов, так что само число MCP-серверов почти не влияет на контекст. Расход контекста дают ответы инструментов. Предупреждение появляется с 10 000 токенов, а потолок по умолчанию — 25 000 (`MAX_MCP_OUTPUT_TOKENS`). Первыми в него упираются скриншоты, DOM-снимки и трассы ([Claude Code: MCP](https://code.claude.com/docs/en/mcp)). Официальные best practices прямо называют CLI-инструменты «the most context-efficient way to interact with external services» ([Best practices](https://code.claude.com/docs/en/best-practices)). Отсюда тренд 2026 года, заметный во всех четырёх областях. Remotion закрыл свой MCP в пользу скилов, Microsoft советует кодинг-агентам Playwright CLI вместо MCP, а Context7 предлагает режим «CLI + Skills» вообще без MCP.

Хорошее описание скила пишется в третьем лице, говорит, что скил делает и когда его применять, и начинается с главного сценария ([Skill authoring best practices](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices)). Это важно из-за бюджета. Список скилов занимает **1 % окна контекста**, текст `description` + `when_to_use` обрезается на 1 536 символах, а при переполнении Claude Code первыми выбрасывает описания скилов, которые вызываются реже всего ([Skills](https://code.claude.com/docs/en/skills)). Если скил не срабатывает сам, вызывайте его явно. `/skill-name` в начале сообщения запускает скил, а то же упоминание в середине фразы только разрешает Claude его вызвать. Скилы из плагинов вызываются как `/plugin:skill` ([Skills](https://code.claude.com/docs/en/skills)). Ставьте только то, что действительно нужно. `/skill-doctor` показывает, сколько стоит каждый скил и как часто его вызывают. `claude plugin details` показывает постоянную стоимость плагина. Через `skillOverrides` низкоприоритетный скил можно оставить в режиме `name-only` ([Skills](https://code.claude.com/docs/en/skills); [Install plugins](https://code.claude.com/docs/en/plugins/install)). Пользу скила проверяйте сравнением: несколько прогонов в свежих сессиях со скилом и без него, через `skillOverrides: {"name":"off"}` или `claude plugin eval` ([Skills](https://code.claude.com/docs/en/skills)). И главное правило для визуальной работы из официальных best practices: «Give Claude a check it can run: tests, a build, a screenshot to compare… If you can't verify it, don't ship it» ([Best practices](https://code.claude.com/docs/en/best-practices)).

## Фронтенду нужны один дизайн-скил, свежие доки и один браузер

Для фронтенда минимальный рабочий набор складывается из шести ролей, и на каждую роль есть вендорский инструмент. Ставить несколько инструментов на одну роль вредно: они занимают место в списке скилов и путают Claude при выборе инструмента.

| Роль | Выбор | Кто поддерживает и чего стоит |
|---|---|---|
| Дизайн-вкус и план токенов | `frontend-design` | Anthropic, официальный маркетплейс, бесплатно |
| Актуальная документация | Context7; для Next.js 16+ встроенные доки и `next-devtools-mcp` | Upstash (работает анонимно, ключ поднимает лимиты); Vercel |
| Компоненты | скил shadcn; при нескольких реестрах ещё shadcn MCP | shadcn, бесплатно |
| Функциональная проверка в браузере | Playwright CLI + skills или Playwright MCP | Microsoft, бесплатно |
| Производительность, Lighthouse, консоль | Chrome DevTools MCP (плагин со скилами) | Google; телеметрия включена по умолчанию |
| Дизайн → код | плагин `figma` (удалённый MCP + скилы) | Figma; на Starter/View — 6 вызовов в месяц |
| Ревью UI и React | `web-design-guidelines`, `react-best-practices` | Vercel, бесплатно |
| Современные веб-API вместо полифиллов | Modern Web Guidance | Google Chrome, preview, телеметрия |

```bash
# В сессии Claude Code
/plugin install frontend-design@claude-plugins-official
/plugin install context7@claude-plugins-official
/plugin marketplace add ChromeDevTools/chrome-devtools-mcp
/plugin install chrome-devtools-mcp@chrome-devtools-plugins

# В терминале
claude plugin install figma@claude-plugins-official
npx skills add shadcn/ui
npm install -g @playwright/cli@latest
playwright-cli install --skills
npx skills add vercel-labs/agent-skills --skill web-design-guidelines --skill react-best-practices -a claude-code
# Только для Next.js 16+
claude mcp add next-devtools npx next-devtools-mcp@latest
```

Почти все команды взяты из README ([frontend-design](https://github.com/anthropics/claude-plugins-official/blob/main/.claude-plugin/marketplace.json); [Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp/blob/main/docs/client-configurations.md); [Figma](https://github.com/figma/mcp-server-guide/blob/main/README.md); [shadcn skills](https://github.com/shadcn-ui/ui/blob/main/apps/v4/content/docs/(root)/skills.mdx); [Playwright CLI](https://github.com/microsoft/playwright-cli/blob/main/README.md); [next-devtools-mcp](https://github.com/vercel/next-devtools-mcp/blob/main/README.md)). Две собраны по общему шаблону. Строка для `context7@claude-plugins-official` повторяет стандартный шаблон официального маркетплейса. Строка с `vercel-labs/agent-skills` собрана по флагам CLI. Если CLI не найдёт скил по имени папки, посмотрите точные имена через `-l`: внутри SKILL.md React-скил называется `vercel-react-best-practices` ([agent-skills](https://github.com/vercel-labs/agent-skills/blob/main/skills/react-best-practices/SKILL.md)). Chrome DevTools MCP можно подключить и без скилов: `claude mcp add chrome-devtools --scope user npx chrome-devtools-mcp@latest`. Но перед установкой плагина такую MCP-only запись нужно удалить ([client-configurations](https://github.com/ChromeDevTools/chrome-devtools-mcp/blob/main/docs/client-configurations.md)).

### frontend-design переписан: туториалы 2025 года описывают другую версию

Anthropic сделала `frontend-design`, чтобы бороться с «distributional convergence»: без подсказок Claude выдаёт «AI slop» — шрифт Inter, фиолетовые градиенты на белом, минимум анимации ([Claude blog](https://claude.com/blog/improving-frontend-design-through-skills)). Текущий SKILL.md заметно отличается от версии из поста ноября 2025 года. Claude в нём играет роль «the design lead at a design studio» и работает в **два прохода**. Сначала он составляет план токенов: 4–6 именованных цветов в hex, шрифты и их роли, ASCII-вайрфрейм. Затем критикует этот план относительно брифа, и только после этого строит интерфейс. Скил прямо перечисляет приметы ИИ-дизайна 2026 года. Это кремовый #F4F1EA с терракотовым акцентом #D97757 (скил отмечает, что это фирменный акцент самой Anthropic). Это «SaaS-card kit» из одинаковых скруглённых карточек. Это капслочные подзаголовки-eyebrows, стрелка «→» на кнопках, фальшивая нумерация 01/02/03 и появление каждой секции через fade-slide-up. Минимальная планка качества: адаптивность до мобильных, видимый фокус клавиатуры и уважение к reduced motion. Слова самого брифа при этом «always win» ([SKILL.md](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)). Практический вывод: советы конца 2025 года вроде «смелые шрифты, слоистые градиенты, каскадные появления» сами стали узнаваемым шаблоном. Новая версия, наоборот, требует сдержанности. README плагина в `anthropics/claude-code` всё ещё описывает старую формулировку, поэтому копии в разных репозиториях могут различаться. Не ставьте весь `example-skills` ради одного скила: он добавляет 12 описаний в каждую сессию, большинство из них не про фронтенд (Slack GIF, внутренние коммуникации). `web-artifacts-builder` рассчитан на артефакты claude.ai и закреплён на Tailwind 3.4.1. `brand-guidelines` воспроизводит бренд Anthropic и полезен только как шаблон для вашего собственного бренд-скила ([web-artifacts-builder](https://github.com/anthropics/skills/blob/main/skills/web-artifacts-builder/SKILL.md); [brand-guidelines](https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md)).

### Доки, компоненты и браузер: по одному инструменту на роль

Главная причина ошибок во фронтенд-коде — устаревшие API из обучающих данных. Context7 ставится командой `npx ctx7 setup --claude` (нужен Node.js ≥22.13). Мастер предлагает режим «CLI + Skills» без MCP или режим MCP. Плагин из официального маркетплейса подключается к хостинговому серверу без Node и «Works anonymously out of the box»; `CONTEXT7_API_KEY` нужен только для повышенных лимитов ([Context7 README](https://github.com/upstash/context7/blob/master/README.md); [плагин context7](https://github.com/anthropics/claude-plugins-official/tree/main/external_plugins/context7)). Для Next.js 16+ лучше подходят документы, соответствующие установленной версии, из `node_modules/next/dist/docs/`. `next-devtools-mcp` теперь только проксирует встроенный эндпоинт `/_next/mcp` (ошибки, маршруты, логи), а инструменты апгрейда из версий 0.3.x переехали в скилы `npx skills add vercel/next.js` ([next-devtools-mcp](https://github.com/vercel/next-devtools-mcp/blob/main/README.md); [vercel-plugin](https://github.com/vercel/vercel-plugin/blob/main/README.md)). Скил shadcn включается, когда в проекте есть `components.json`. Он запускает `shadcn info --json` и навязывает правила: семантические цвета вместо `bg-blue-500`, `flex gap-*` вместо `space-y-*`, `size-10` вместо `w-10 h-10`. Обычно одного скила хватает, а MCP (`npx shadcn@latest mcp init --client claude`) нужен, только если вы работаете с несколькими реестрами компонентов ([shadcn SKILL.md](https://github.com/shadcn-ui/ui/blob/main/skills/shadcn/SKILL.md); [shadcn MCP](https://github.com/shadcn-ui/ui/blob/main/apps/v4/content/docs/(root)/mcp.mdx)). У Google Modern Web Guidance есть внутренний eval мейнтейнеров на 153 задачах: с этим набором Claude Code вырос **с 59 % до 87 % на sonnet-5-5** и с 61 % до 89 % на opus-5-5. Набор при этом стоит около 234 токенов. Проект в статусе preview и собирает поисковые запросы агента. Ставится так: `/plugin marketplace add GoogleChrome/modern-web-guidance`, затем `/plugin install modern-web-guidance@googlechrome` ([README](https://github.com/GoogleChrome/modern-web-guidance/blob/main/README.md)).

Браузерных инструментов много, но рабочая схема одна: **один инструмент для автоматизации плюс Chrome DevTools MCP для перф-задач**. Playwright MCP (Microsoft, 38,4k★) действует по accessibility-снимкам. Скриншоты в нём только для просмотра: «You can't perform actions based on the screenshot». Сам Microsoft пишет, что кодинг-агентам выгоднее «CLI+SKILLS… CLI invocations are more token-efficient», а MCP оставляет для исследовательских и долгих автономных сценариев ([Playwright MCP README](https://github.com/microsoft/playwright-mcp/blob/main/README.md)). Если всё же выбираете MCP, команда из README — `claude mcp add playwright npx @playwright/mcp@latest`. Полезные флаги: `--headless`, `--mobile` (экономит токены) и `--isolated` для параллельных сессий, потому что постоянный профиль может использовать только один браузер. Chrome DevTools MCP (Google, 53,8k★) даёт 59 инструментов. Среди них `lighthouse_audit` (доступность, SEO, best practices, но не производительность), `performance_start_trace` с `performance_analyze_insight` и консоль с source maps. Для простых задач есть режим `--slim` ([tool-reference](https://github.com/ChromeDevTools/chrome-devtools-mcp/blob/main/docs/tool-reference.md)). Без MCP можно обойтись двумя способами. Первый — `agent-browser` от Vercel (`npm install -g agent-browser`, затем `agent-browser install`) с экономным `screenshot --if-changed` ([agent-browser](https://github.com/vercel-labs/agent-browser/blob/main/README.md)). Второй — встроенный Claude in Chrome (`claude --chrome`): он требует прямой подписки Anthropic и расширения v1.0.36+ и не работает в WSL ([Claude Code: Chrome](https://code.claude.com/docs/en/chrome)).

Плагин Figma объединяет удалённый MCP и скилы. `get_design_context` возвращает «structured React + Tailwind representation» выделенного фрагмента, и Figma прямо требует считать это описанием дизайна, а не финальным кодом. Порядок такой: сначала `get_design_context`; если ответ обрезан, `get_metadata` и повторный запрос нужных узлов; затем `get_screenshot`; и только потом ассеты. SVG и картинки с localhost-источника используются как есть, а новые пакеты иконок не добавляются ([figma/mcp-server-guide](https://github.com/figma/mcp-server-guide/blob/main/README.md)). **Главная ловушка — тарифы.** На Starter и на местах View/Collab доступно «up to 6 tool calls per month», то есть сервер почти бесполезен. Нормальные лимиты появляются только у мест Dev/Full на платных планах. Запись на холст бесплатна, пока идёт бета, а потом станет платной функцией ([README](https://github.com/figma/mcp-server-guide/blob/main/README.md)). Без такого места практичная замена — community Framelink (`GLips/Figma-Context-MCP`, 16k★), который работает с персональным токеном ([Framelink](https://github.com/GLips/Figma-Context-MCP/blob/main/README.md)). Десктопный Figma MCP сама Figma больше не рекомендует и советует удалённый ([Figma Help](https://help.figma.com/hc/en-us/articles/35281385065751-Figma-MCP-collection-Compare-Figma-s-remote-and-desktop-MCP-servers)).

У `nextlevelbuilder/ui-ux-pro-max-skill` **137,5k★ за 11 месяцев** и платная Premium-версия. Не складывайте несколько «вкусовых» скилов вместе (frontend-design, ui-ux-pro-max, superdesign, ui-craft): у каждого свои эстетические правила. Хватит одного дизайн-скила и одного ревью-скила. ## В SVG официального скила нет, и качество даёт цикл «рендер → PNG → правка»

У всех сильных community-скилов одна общая черта: встроенный цикл «отрендерить → посмотреть PNG → исправить». Claude хорошо пишет SVG как код, но плохо оценивает результат, пока его не увидит. Типичные дефекты, которые ловит цикл, — «misaligned joints, wrong proportions, flat colors». На персонажа уходит 5–8 итераций: сначала торс, потом конечности по одной, с рендером после каждого шага ([svg-creator-skill](https://github.com/upbrew-tech/svg-creator-skill/blob/main/SKILL.md)). ### Какие инструменты выбрать и почему

`logo-design-skill` сильнее остальных, потому что проверка в нём реализована инструментами. Python-утилиты без зависимостей проверяют SVG и собирают тест-листы: пиксельный тест на 16 px, одноцветный, инверсный, «squint», зеркальный и тест на «полке» рядом с конкурентами. Скил также экспортирует наборы favicon и app-icon. После трёх концептов он **всегда останавливается и ждёт вашего выбора**. Для PNG он берёт любой доступный рендерер: cairosvg, rsvg-convert, Inkscape или Chromium. Ему нужна модель, которая умеет смотреть на изображения ([README](https://github.com/kaankiziltug/logo-design-skill)). Официальный draw.io-плагин создаёт нативные `.drawio` с выгрузкой в SVG/PNG/PDF со встроенным XML, так что экспорт остаётся редактируемым. Для раскладки используйте либо ELK (`postLayout: "elk"`), либо libavoid, «Pick one, not both». Учтите, что плагин включает и хостинговый App Server, а `mcp.draw.io` получает содержимое диаграммы ([drawio-mcp](https://github.com/jgraph/drawio-mcp)). Для Excalidraw в терминале лучше yctimlin/mcp_excalidraw, а не официальный `excalidraw/excalidraw-mcp`. Официальный сервер — это одноразовый виджет «prompt in, diagram out» без экспорта для модели. У yctimlin 26 инструментов, рендер без браузера через resvg и CLI-команды `render` и `export` ([mcp_excalidraw](https://github.com/yctimlin/mcp_excalidraw); [excalidraw-mcp](https://github.com/excalidraw/excalidraw-mcp)). D2 переехал из `terrastruct/d2` в `d2lang/d2`, и `d2 --watch in.d2 out.svg` даёт живую перезагрузку ([d2lang/d2](https://github.com/d2lang/d2)). Для анимации официальные `gsap-skills` от GreenSock покрывают core, timeline, ScrollTrigger и SVG-плагины. После покупки Webflow «GSAP is 100% free — including every plugin… (SplitText, MorphSVG, etc.)» ([gsap-skills](https://github.com/greensock/gsap-skills)).

### Как устроен цикл и где ломается SVGO

Рендерер для самопроверки должен быть под рукой в PATH. **resvg** — одиночный CLI меньше 5 МБ без внешних зависимостей, примерно с 1 600 регрессионными тестами. Но он рендерит только статику: «No animations», «No native text rendering» ([resvg](https://github.com/linebender/resvg)). Поэтому логотипы с текстом для финала переводите в кривые и сверяйте в браузере, а анимированные SVG снимайте через Playwright или Chrome DevTools в нескольких моментах времени. `rsvg-convert` без `-w`/`-h` берёт заявленный размер SVG, и PNG может получиться крошечным ([techearl](https://techearl.com/convert-svg-to-png-command-line)). У Inkscape 1.x синтаксис `--export-type=png --export-filename=out.png`, а старые флаги `-e`/`-f` больше не работают ([Inkscape man](https://tribblix.org/man/man1/inkscape.html)).

```bash
# Рендер черновика, PNG затем показать Claude через Read
resvg logo.svg logo.png -w 512          # или: rsvg-convert -w 512 logo.svg -o logo.png
# После итераций: оптимизация и повторный рендер для сверки
svgo logo.svg -o logo.min.svg
```

```js
// svgo.config.mjs: щадящий вариант для анимируемых SVG (синтез, сверьте с документацией SVGO)
export default {
  multipass: true,
  plugins: [
    { name: 'preset-default', params: { overrides: {
      cleanupIds: false, collapseGroups: false, convertShapeToPath: false, mergePaths: false,
    } } },
  ],
};
```

В **SVGO v4** (сейчас 4.1.0) плагины `removeViewBox` и `removeTitle` убраны из `preset-default`, «to preserve scalability» и «to preserve accessibility». Туториалы под v3, да и, по поисковой выдержке, сама страница svgo.dev могут ещё показывать старый состав ([migration v3→v4](https://svgo.dev/docs/migrations/migration-from-v3-to-v4/); [preset-default.js](https://github.com/svg/svgo/blob/main/plugins/preset-default.js)). Опасным для анимации остаётся `cleanupIds`, который включён по умолчанию: он «removes unused IDs and minifies used» и ломает селекторы, на которые ссылаются CSS и GSAP. Отключайте его через `overrides`, а для инлайна нескольких SVG на одну страницу используйте `prefixIds` ([cleanupIds.js](https://github.com/svg/svgo/blob/main/plugins/cleanupIds.js); [SVGO README](https://github.com/svg/svgo)). Отключение `collapseGroups`, `convertShapeToPath` и `mergePaths` в конфиге выше — это вывод исследователей, а не цитата из документации. Эти плагины перестраивают структуру элементов, на которую ссылается анимация. SVGR стоит проверить перед использованием: `@svgr/cli` 8.1.0 последний раз публиковался **15 августа 2023 года**. В новых проектах иногда проще попросить Claude перевести SVG в JSX вручную ([npm @svgr/cli](https://www.npmjs.com/package/@svgr/cli)). Для доступности информативный SVG получает `role="img"` и `<title id>` со ссылкой через `aria-labelledby`, декоративный — `aria-hidden="true"` ([TPGi](https://tpgi.com/using-aria-enhance-svg-accessibility)). Анимированный SVG должен включать медиазапрос `prefers-reduced-motion`. CSS-трансформации дочерних элементов требуют `transform-box: fill-box`, а внутри `<img>` анимация работает только через SMIL ([svg-creator-skill](https://github.com/upbrew-tech/svg-creator-skill)).

Подводные камни. README `upbrew-tech/svg-creator-skill` даёт команду-заглушку `/plugin marketplace add YOUR_USERNAME/svg-creator-skill`, а сам SKILL.md прописывает пути песочницы claude.ai (`/home/claude/draft.svg`, `/mnt/user-data/outputs/`). Методика у скила правильная, но для Claude Code его нужно править ([SKILL.md](https://github.com/upbrew-tech/svg-creator-skill/blob/main/SKILL.md)). Локальный `recraft-ai/mcp-recraft-server` заархивирован: «Deprecated… No further updates, bug fixes, or security patches». Удалённый сервер использует OAuth и другую модель кредитов ([README](https://github.com/recraft-ai/mcp-recraft-server)). Платная альтернатива — SVGMaker; его облачный сервер не умеет писать файлы на диск ([svgmaker-mcp](https://github.com/GenWaveLLC/svgmaker-mcp)). Официального MCP для Iconify нет: npm-имя `@iconify/mcp` возвращает 404. Самый заметный сторонний `iconify-mcp-server` набрал 19★, а npm-пакет `svgo-mcp` вообще не ссылается на репозиторий ([npm @iconify/mcp](https://www.npmjs.com/package/@iconify/mcp); [iconify-mcp-server](https://github.com/imjac0b/iconify-mcp-server); [svgo-mcp](https://www.npmjs.com/package/svgo-mcp)). Для векторизации растра локально подходит vtracer, который в отличие от potrace работает с цветными изображениями. Но в README описан API 1.0-alpha, а на PyPI стабильная версия 0.6.15 ([vtracer](https://github.com/visioncortex/vtracer); [PyPI](https://pypi.org/project/vtracer/)).

Рендерить только на «Render the video», «Export» или «Give me the MP4». Не перезаписывать неожиданные правки пользователя ([remotion-best-practices](https://github.com/remotion-dev/remotion/blob/main/packages/skills/skills/remotion-best-practices/SKILL.md)). Дешёвая визуальная проверка — пара стоп-кадров вместо полного MP4: `npx remotion render [composition-id] out/frames --frames=0,30,90 --image-format=png` ([remotion-render](https://github.com/remotion-dev/remotion/blob/main/packages/skills/skills/remotion-render/SKILL.md)). Субтитры скил генерирует через `@remotion/whisper-webgpu`. Этому пакету нужен совместимый GPU, а ONNX Runtime не работает на Linux arm64. CPU-путь через `@remotion/install-whisper-cpp` по-прежнему документирован ([transcribe-captions](https://github.com/remotion-dev/remotion/blob/main/packages/skills/skills/remotion-captions/transcribe-captions.md); [install-whisper-cpp](https://www.remotion.dev/docs/install-whisper-cpp)). При обновлении Remotion обновляйте и скилы (`npx remotion skills update` или `/remotion-upgrade`), иначе они начнут советовать устаревший API. **Лицензия:** бесплатно для частных лиц, некоммерческих организаций и коммерческих компаний до 3 сотрудников, остальным нужна Company License. В Remotion 5.0 лицензия «slightly change» ([LICENSE.md](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md)).

HyperFrames от HeyGen превращает HTML, CSS, медиа и анимации с перемоткой в детерминированный MP4. Лицензия Apache-2.0, нужны Node.js 22+ и FFmpeg. У проекта 67,3k★ и релиз v0.8.175 от 19 октября 2026 года ([README](https://github.com/heygen-com/hyperframes)). После установки плагина точка входа — `/hyperframes:hyperframes`. Готовые сценарии: `/product-launch-video` (оптимальная длина 30–90 с), `/embedded-captions`, `/talking-head-recut`, `/motion-graphics` (в том числе прозрачный оверлей), `/pr-to-video` и `/remotion-to-hyperframes`. Цикл работы задают CLI-команды `preview`, `lint`, `check`, `snapshot` и `render` ([README](https://github.com/heygen-com/hyperframes)). HyperFrames есть и в официальном маркетплейсе под именем `hyperframes` ([marketplace.json](https://github.com/anthropics/claude-plugins-official/blob/main/.claude-plugin/marketplace.json)). Выбор между ними простой. Remotion подходит, если команда знает React или нужен `<Player>`, Lambda или встраивание в SaaS. HyperFrames — если вам ближе HTML/GSAP и не хочется разбираться с корпоративной лицензией. У Revideo и Motion Canvas проверенного официального набора скилов нет. Их конвенции придётся описать в собственном `.claude/skills/<name>/SKILL.md` ([Revideo](https://github.com/redotvideo/revideo); [Motion Canvas](https://github.com/motion-canvas/motion-canvas)).

### Для монтажа Bash с ffmpeg надёжнее универсального FFmpeg-MCP

Самый успешный агентный монтажёр, video-use от Browser Use (29,3k★), — это скил, а не MCP. Его принцип: «The LLM never watches the video. It **reads** it». Claude получает упакованный транскрипт (около 12 КБ на все дубли) и по запросу PNG-ленту из кадров, волновой формы и меток слов. Прямой подход стоил бы «30,000 frames × 1,500 tokens = 45M tokens of noise» ([video-use README](https://github.com/browser-use/video-use)). Скил сам проверяет результат на каждой склейке и перерендеривает не больше трёх раз. Он ещё молодой (23 коммита) и транскрибирует только через ElevenLabs Scribe, поэтому нужен API-ключ. Его «Hard Rules» стоит переписать в собственный CLAUDE.md. Субтитры добавлять последним шагом цепочки. Склеивать без перекодирования через `-c copy`. На каждой границе давать аудиофейды по 30 мс. Никогда не резать внутри слова. Добавлять запас 30–200 мс, потому что «Scribe timestamps drift 50–100ms» ([video-use SKILL.md](https://github.com/browser-use/video-use/blob/main/SKILL.md)). auto-editor (5,6k★, общественное достояние) — стандарт для вырезания пауз, и у него есть официальный скил. Отступы по краям задаются через `--margin 0.2sec`. Режим `--when-active cut --when-inactive nil` показывает, что будет вырезано, ничего не удаляя. `--export resolve|premiere|final-cut-pro` отдаёт таймлайн в монтажную программу ([auto-editor](https://github.com/WyattBlue/auto-editor)). Kinocut (бывший mcp-video, 203 инструмента, v1.16.1 от 5 октября 2026) нужен, только если требуются типизированные ограничители для запусков без присмотра ([Kinocut](https://github.com/KyaniteLabs/kinocut)). `misbahsy/video-audio-mcp` с последним коммитом в мае 2025 года заброшен ([video-audio-mcp](https://github.com/misbahsy/video-audio-mcp)).

Проверку результата собирают из машиночитаемых сигналов. Ниже стандартные команды ffmpeg. Исследователи их не запускали, поэтому сверьте флаги с `--help`. Метаданные: `ffprobe -v error -show_streams -of json out.mp4`. Кадр в точке склейки: `ffmpeg -ss <t> -i out.mp4 -frames:v 1 check_<t>.png`. Контакт-лист: `ffmpeg -i out.mp4 -vf "fps=1/5,scale=320:-1,tile=4x4" sheet.png`. Громкость: `-af loudnorm=print_format=json`. whisper.cpp принимает только 16-битный WAV ([whisper.cpp](https://github.com/ggml-org/whisper.cpp)), поэтому перед транскрипцией выполните `ffmpeg -i in.mp4 -ar 16000 -ac 1 -c:a pcm_s16le in.wav`. В FFmpeg 8.0 появился встроенный Whisper-фильтр ([FFmpeg Changelog](https://github.com/FFmpeg/FFmpeg/blob/master/Changelog)). Для соцсетей выдавайте H.264 с `-pix_fmt yuv420p -movflags +faststart`. Долгие рендеры запускайте в фоне.

### Монтажные программы и генерация: где нужна платная версия

DaVinci Resolve MCP (`samuelgursky/davinci-resolve-mcp`, 3,6k★, v4.14.4 от 19.10.2026) — самый зрелый мост к монтажной программе. В компактном режиме у него 37 составных инструментов, в режиме `--full` — 390. Его проверяли на Resolve 19–21. Но **«Blackmagic gates external scripting to Studio»**, а обходной мост для бесплатной версии закрылся с выходом 21.1: «Resolve 21.1 moved Python scripting to Studio». Перед подключением включите Preferences > General > External scripting using → Local и начинайте с компактного режима ([README](https://github.com/samuelgursky/davinci-resolve-mcp)). Для Premiere самый рабочий вариант — `hetpatel-11/Adobe_Premiere_Pro_MCP`: 283 инструмента, установка `npm install -g adobe-premiere-pro-mcp` и `premiere-pro-mcp --install-cep`. Он работает через CEP (UXP пока экспериментальный), его пакет `.mcpb` не подписан, и в README есть раздел о телеметрии ([README](https://github.com/hetpatel-11/Adobe_Premiere_Pro_MCP)). MCP для After Effects базовые, ExtendScript-панель Dakkshin последний раз обновлялась в апреле 2026 года ([after-effects-mcp](https://github.com/Dakkshin/after-effects-mcp)). Для CapCut и Jianying есть VectCutAPI (бывший CapCutAPI), но он привязан к облаку VectCut ([VectCutAPI](https://github.com/sun-guannan/VectCutAPI)). Если у вас бесплатный Resolve, надёжнее резать в Bash и передавать XML через `auto-editor --export resolve`. Официальный коннектор Adobe for creativity — хостинговый: 50+ инструментов, требует подписку Creative Cloud. Таймлайном десктопного Premiere он не управляет (вторичные источники) ([weandthecolor](https://weandthecolor.com/how-does-the-adobe-for-creativity-connector-work-in-claude/210357)).

Для генерации используйте хостинговые официальные серверы. Локальный `elevenlabs-mcp` объявлен устаревшим в пользу `https://api.elevenlabs.io/v1/mcp` с OAuth ([elevenlabs-mcp](https://github.com/elevenlabs/elevenlabs-mcp)). Команда `claude mcp add --transport http elevenlabs https://api.elevenlabs.io/v1/mcp` выведена из общего синтаксиса, в документации ElevenLabs её не проверяли. Репозиторий `runwayml/runway-api-mcp-server` заархивирован ([Runway](https://github.com/runwayml/runway-api-mcp-server)). При этом в официальном маркетплейсе есть плагин `runway-api` ([marketplace.json](https://github.com/anthropics/claude-plugins-official/blob/main/.claude-plugin/marketplace.json)), так что перед установкой проверьте, что именно он подключает. Luma MCP не обновлялся с апреля 2025 года ([luma-api-mcp](https://github.com/lumalabs/luma-api-mcp)). Kling, Veo, LTX и похожие модели удобнее вызывать через агрегаторы. Это fal (`mcp.fal.ai/mcp`, ключ в заголовке Bearer; источник вторичный) ([fal docs](https://fal.ai/docs/documentation/setting-up/mcp)) и Replicate: `claude mcp add replicate https://mcp.replicate.com/sse --transport sse --scope user`, затем `/mcp` ([Replicate docs](https://replicate.com/docs/reference/mcp)). У этой команды Replicate транспорт SSE, который в Claude Code объявлен устаревшим. Google публикует Genmedia MCP для Veo 3.1, Lyria и Chirp в каталоге `experiments/` ([mcp-genmedia](https://github.com/GoogleCloudPlatform/vertex-ai-creative-studio/tree/main/experiments/mcp-genmedia)). Каждый вызов генерации платный, поэтому задайте бюджеты.

### Blender: два MCP с разными сильными сторонами

Community-сервер **переименован**: `blender-mcp` стал `ahujasid/mcp-for-blender`, PyPI-пакет теперь `mcp-for-blender`. Старый `uvx blender-mcp` по-прежнему работает ([GitHub](https://github.com/ahujasid/mcp-for-blender)). После двух команд из блока выше включите в Blender аддон **Interface: MCP for Blender**, нажмите `N` во вьюпорте и затем **Start MCP Server**. `uv` ставьте официальным установщиком, а не через `pip install uv`, иначе `uvx` может не появиться. Сам `uvx` в терминале не запускайте: сервер стартует MCP-клиент. Автоматическая установка `uvx mcp-for-blender setup` правит конфиги Claude Code, Codex, Cursor и VS Code и оставляет `.bak`-копии ([README](https://github.com/ahujasid/mcp-for-blender#quickstart)). Сервер даёт девять инструментов. Главные — `execute_blender_code`, `get_scene_info` и `look`. `look` в режиме `angles` возвращает лист с несколькими ракурсами для самопроверки, в режиме `frames` — анимационную ленту. Есть также ассеты Poly Haven (около 2 400 моделей под CC0) и Poly Pizza (около 69 % под CC-BY, атрибуция пишется в свойство `polypizza_attribution`). Генерация `generate_3d` идёт через Tripo, Hunyuan3D, Rodin и Meshy, причём Meshy требует ключ платного плана ([Capabilities](https://github.com/ahujasid/mcp-for-blender#capabilities)). Рабочий цикл: `get_scene_info`, небольшой `execute_blender_code`, `look(view="angles")`, правка. Сложные операции дробите. Текстуры Poly Haven просите в разрешении 1k–2k: загрузка идёт в главном потоке и подвешивает интерфейс ([Troubleshooting](https://github.com/ahujasid/mcp-for-blender#troubleshooting)). Скачивание с `static.poly.pizza` блокирует Cloudflare для IP дата-центров и VPN, что важно для облачных сессий ([README](https://github.com/ahujasid/mcp-for-blender#capabilities)).

Официальный Blender Lab MCP (v1.0.x, Blender 5.1+, GPL) намеренно минимален, зато вшивает справочник bpy API и выдержки из мануала. У него есть варианты инструментов `_for_cli` для фонового Blender без интерфейса. Для Claude Code его ставят из исходников через `.mcp.json`: `"command": "uv", "args": ["--directory", "/abs/path/blender_mcp/mcp", "run", "blender-mcp"]`, путь абсолютный ([blender.org/lab](https://www.blender.org/lab/mcp-server/); [issue #23](https://projects.blender.org/lab/blender_mcp/issues/23); [зеркало](https://github.com/SJJ-universe/blender-lab-mcp)). Его «песочница» по признанию авторов «isn't really a sandbox… more of a slap on the wrist» ([weak_sandbox.py](https://github.com/SJJ-universe/blender-lab-mcp/blob/main/addon/blender_mcp_addon/weak_sandbox.py)). Ставить оба сервера под одним именем `blender` нельзя: у обоих по умолчанию TCP-сокет, поэтому разведите имена и порты. Для фона: 28 апреля 2026 года Anthropic выпустила «Claude for Creative Work» с девятью коннекторами, среди которых Blender, Adobe, Autodesk Fusion и SketchUp, и стала корпоративным патроном Blender Development Fund ([RedShark News](https://www.redsharknews.com/anthropic-claude-creative-connectors-adobe-blender-autodesk)). Из других DCC зрелые community-MCP есть у Houdini (`pip install fxhoudinimcp` и `python -m fxhoudinimcp install`, Houdini 20.5+, 215 инструментов) и у 3ds Max (только Windows, 160 инструментов). Официального Autodesk-MCP для Maya не найдено ([fxhoudinimcp](https://github.com/healkeiser/fxhoudinimcp); [3dsmax-mcp](https://github.com/cl0nazepamm/3dsmax-mcp); [Vagon](https://vagon.io/blog/how-to-use-claude-code-with-maya)).

### Движки: официальные MCP появились, но community пока зрелее

В Unity стандартный выбор — CoplayDev MCP for Unity: v10.3.0, Unity от 2021.3 LTS до 6.x. Пакет ставится через Package Manager по git URL `https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#main`, затем выполните `Window → MCP for Unity → Configure All Detected Clients` ([GitHub](https://github.com/CoplayDev/unity-mcp)). По умолчанию по HTTP (`http://localhost:8080/mcp`) включена только группа инструментов `core`. Остальные девять групп, включая `asset_gen` с `generate_model`, включаются через `manage_tools` ([v10 migration](https://github.com/CoplayDev/unity-mcp/blob/beta/website/docs/migrations/v10.md)). Встроенный скил `unity-mcp-orchestrator` задаёт порядок: прочитать состояние редактора, найти объекты, выполнить действие, проверить `read_console` и скриншот камеры, после `create_script` дождаться компиляции ([SKILL.md](https://github.com/CoplayDev/unity-mcp/blob/beta/unity-mcp-skill/SKILL.md)). Официальный Unity MCP входит в пакет AI Assistant, требует Unity 6+, подписку Unity и активный trial или подписку Unity AI ([Unity blog](https://unity.com/blog/unity-ai-mcp-how-to-get-started)). Точной команды для Claude Code в его документации не найдено. IvanMurzak «AI Game Developer» требует OAuth-входа на ai-game.dev и по умолчанию смотрит на облачный эндпоинт ([Unity-MCP](https://github.com/IvanMurzak/Unity-MCP)).

Epic добавила официальный **Unreal MCP в UE 5.8 как experimental**. Нужно включить плагины Unreal MCP и All Toolsets. Эндпоинт — `http://127.0.0.1:8000/mcp`, принимаются только локальные соединения, аутентификации нет. Конфиг клиента генерирует консольная команда `ModelContextProtocol.GenerateClientConfig` ([Epic docs](https://dev.epicgames.com/documentation/unreal-engine/unreal-mcp-in-unreal-editor?lang=en-US)). Для UE 5.3–5.7 официального решения нет. Там выбирают ChiR24/Unreal_mcp (UE 5.0–5.8, нативный C++, токен-защита по умолчанию). Популярный `chongdashu/unreal-mcp` (2,1k★) не обновлялся с 22 апреля 2025 года, а `flopperam` превратился в коммерческий хостинговый сервис ([Unreal_mcp](https://github.com/ChiR24/Unreal_mcp); [chongdashu](https://github.com/chongdashu/unreal-mcp); [flopperam](https://github.com/flopperam/unreal-engine-mcp)). Официального Godot MCP нет. `Coding-Solo/godot-mcp` подходит для цикла «запустить проект → прочитать ошибки», а `hi-godot/godot-ai` от авторов MCP for Unity — для работы в живом редакторе. Цепочка у godot-ai аутентифицированная, поэтому голая запись `http://127.0.0.1:8000/mcp` не подключится ([godot-ai](https://github.com/hi-godot/godot-ai)).

### Веб-3D: устаревший API three.js и чёрные кадры в headless

Главная проблема при генерации three.js-кода — API из обучающих данных устарел. Между r160 и r186 `RGBELoader` стал `HDRLoader`, `Clock` уступил место `Timer`, `PostProcessing` стал `RenderPipeline`, поддержку WebGL 1 убрали. Документация three.js теперь советует LLM `WebGPURenderer` с TSL ([threejs-skills README](https://github.com/CloudAI-X/threejs-skills#why)). Поэтому базовый выбор — `CloudAI-X/threejs-skills`: 13 скилов под r186, R3F 9.8 и drei 10.7 со списками «Common Mistakes» ([GitHub](https://github.com/CloudAI-X/threejs-skills)). Поверх него по задаче добавляют `majidmanzarpour/threejs-game-skills` (Playwright-QA и visual regression, `npx skills add majidmanzarpour/threejs-game-skills --skill '*' -a claude-code -g -y`) или `scottstts/Threejs-Awesome-Graphics-Agent-Skills` для качества картинки ([game-skills](https://github.com/majidmanzarpour/threejs-game-skills); [Awesome Graphics](https://github.com/scottstts/Threejs-Awesome-Graphics-Agent-Skills)). Официального скила от pmndrs нет. У Spline официальный MCP встроен в десктопное приложение и работает с Claude Code, а старый `aydinfer/spline-mcp-server` заархивирован ([Spline docs](https://docs.spline.design/generate/spline-mcp-server)). Accessibility-снимок не видит содержимого canvas, поэтому проверка возможна только скриншотом. Цикл такой: `browser_navigate`, дождаться флага готовности кадра (например, `window.__frameReady = true` после первого `renderer.render`), `browser_take_screenshot`, затем `browser_console_messages` для шейдерных ошибок ([Playwright MCP](https://github.com/microsoft/playwright-mcp)). В headless не используйте `--disable-gpu`: в Chrome 130+ он ломает WebGL. Программный WebGL включается флагами `--use-gl=angle --use-angle=swiftshader-webgl --enable-unsafe-swiftshader`, и их можно использовать только с доверенным контентом. Headless-захват WebGPU на Linux не поддерживается (вторичные источники) ([microlink](https://microlink.io/blog/webgl-without-a-gpu); [agent-browser](https://agent-browser.dev/webgpu)).

### AI-генерация и CAD: инструменты, которые измеряют результат

Из генераторов моделей для Claude Code реально работают два официальных MCP. Hyper3D Rodin даёт хостинговый `https://api.hyper3d.com/api/mcp` с входом через браузер, и Claude Code указан среди поддерживаемых клиентов. Точную команду получить не удалось, но, судя по описанию, это `claude mcp add --transport http hyper3d-rodin https://api.hyper3d.com/api/mcp` ([hyper3d.ai](https://hyper3d.ai/ko/features/mcp)). Второй — Meshy MCP: 28 инструментов, включая риггинг, анимацию и проверку печатаемости с починкой. Нужен ключ плана Pro, оплата идёт кредитами. **`model_type: "lowpoly"` отключается 30 октября 2026 года**, замена — `smart-topology` с `meshy-t2`. На Windows используйте `add-json`, иначе получите ошибку `unknown option '-y'` ([meshy-mcp-server](https://github.com/meshy-dev/meshy-mcp-server)). Официальный `tripo-mcp` остаётся в alpha с апреля 2025 года и работает только через Blender-аддон Tripo ([tripo-mcp](https://github.com/VAST-AI-Research/tripo-mcp)). Если модель нужна сразу в сцене, генерируйте через DCC: Blender `generate_3d` или Unity `generate_model`. Тогда масштаб и материалы проверяются скриншотом в том же цикле.

В CAD сильная сторона Claude — код, и лучше всего работают MCP, которые исполняют скрипт, рендерят виды и измеряют геометрию. Пример: `pzfreo/build123d-mcp` на CADGenBench (июнь 2026) поднял у той же модели score **с 0,360 до 0,457, а валидность CAD — с 88 % до 100 %**. Конфиг для `.mcp.json`: `"command": "uv", "args": ["tool", "run", "--python", "3.12", "build123d-mcp@latest"]` ([build123d-mcp](https://github.com/pzfreo/build123d-mcp)). `openscad-mcp` рендерит «with a stated scale», проверяет сборки на пересечения и закрепляется на версии через `uvx openscad-mcp@0.6.1` ([openscad-mcp](https://github.com/RobertCoop/openscad-mcp)). `agentcad` рендерит виды командой `agentcad render output.step --view top,front,right,iso`. Он работает только на Python 3.10–3.12, потому что «OpenCascade bindings do not support 3.13+» ([agentcad](https://github.com/jdilla1277/agentcad)). `neka-nat/freecad-mcp` (`uvx freecad-mcp`, 3k★) даёт скриншоты вида, headless-скрипты и FEM на CalculiX ([freecad-mcp](https://github.com/neka-nat/freecad-mcp)). Для Fusion 360 официальный коннектор Autodesk ориентирован на Claude Desktop. Community-сервер ставится командой `claude mcp add fusion360 -- uvx fusion360-mcp-server --mode socket` и слушает `localhost:9876` без аутентификации ([fusion360-mcp-server](https://github.com/faust-machines/fusion360-mcp-server)). Общий порядок проверки для CAD: виды iso/front/top, габариты и объём, проверка на водонепроницаемость и манифолдность, и только потом экспорт.

## Каждый сторонний скил и MCP — это чужой код с вашими правами

Официальная документация формулирует угрозу прямо: «A Claude Code plugin you install can execute arbitrary code on your machine with your user privileges». Хуки, мониторы, MCP- и LSP-серверы работают **вне песочницы и вне правил разрешений**, которые покрывают только вызовы инструментов самим Claude ([Plugin security](https://code.claude.com/docs/en/plugins/security)). Скилы попадают в контекст как инструкции, и вредоносный скил может «direct Claude to invoke tools or execute code in ways that don't match the Skill's stated purpose» ([Claude Platform](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview)). Есть две неочевидные дыры. Во-первых, `allowed-tools` проектного скила применяется даже в `claude -p` в папке, которой вы никогда не доверяли ([Skills](https://code.claude.com/docs/en/skills)). Во-вторых, `-p`, Agent SDK и облачные сессии подключают серверы из `.mcp.json` без вопроса ([Claude Code: MCP](https://code.claude.com/docs/en/mcp)). При включённом автообновлении «the files you reviewed can change on disk». Автообновление включено по умолчанию у официальных маркетплейсов и выключено у сторонних ([Plugin security](https://code.claude.com/docs/en/plugins/security); [Install plugins](https://code.claude.com/docs/en/plugins/install)).

Угроза подтверждается реальными находками. Snyk в феврале 2026 года просканировал 3 984 скила из ClawHub и skills.sh. У **13,4 % (534 скила)** нашлась хотя бы одна критическая проблема: распространение вредоносного ПО, prompt injection или открытые секреты. У 36,82 % нашёлся дефект любой степени. Цифры взяты из пересказов, а AgentGuard, вопреки Snyk, называет 1 467 случаев «malicious payloads» ([Snyk ToxicSkills](https://snyk.io/blog/toxicskills-malicious-ai-agent-skills-clawhub); [AgentGuard](https://agentguard.gopluslabs.io/advisor/AGS-2026-0006)). Koi Security нашла 341 вредоносный скил из 2 857 в реестре ClawHub. Они ставили macOS-стилер Atomic Stealer через фальшивые «Prerequisites»: скачать ZIP с паролем или запустить обфусцированный shell-скрипт ([Koi: ClawHavoc](https://koi.ai/blog/clawhavoc-341-malicious-clawedbot-skills-found-by-the-bot-they-were-targeting); [The Hacker News](https://thehackernews.com/2026/02/researchers-find-341-malicious-clawhub.html)). ClawHub — реестр OpenClaw, но формат скилов тот же, а skills.sh входил в выборку Snyk. У MCP свои атаки. «Tool poisoning» прячет инструкции в описании инструмента. «Rug pull» подменяет определения инструментов уже после одобрения. «Line jumping» от Trail of Bits срабатывает при одном только подключении сервера, до первого вызова ([Trail of Bits](https://blog.trailofbits.com/2025/04/21/jumping-the-line-how-mcp-servers-can-attack-you-before-you-ever-use-them/); [CSA](https://labs.cloudsecurityalliance.org/research/csa-research-note-mcp-tool-poisoning-auto-execution-20260701/)).

Порядок проверки перед установкой такой. Предпочитайте официальный маркетплейс, `anthropics/skills` и репозитории самих вендоров (Microsoft, Google, Figma, Remotion, HeyGen, GreenSock, jgraph). Community-маркетплейс `claude-community` надёжнее случайных репозиториев, потому что почти все записи в нём закреплены на SHA коммита. Awesome-списки годятся только как способ найти исходный репозиторий, а индексы-краулеры (SkillsMP, claude-plugins.dev, поиск skills.sh) никто не проверяет ([Plugin security](https://code.claude.com/docs/en/plugins/security); [SmartScope](https://smartscope.blog/en/blog/skillsmp-marketplace-guide/)). Прочитайте SKILL.md и все скрипты. Ищите `curl | bash`, «предварительные» загрузки, обфускацию и обращения к `~/.ssh`, `.env` и профилям браузера. В плагине отдельно проверьте `allowed-tools`, `hooks/hooks.json`, `.mcp.json` и каждый файл в `bin/`. Опись компонентов без запуска сессии даёт `claude --plugin-dir <clone> plugin details <name>`, а установленные файлы лежат в `~/.claude/plugins/cache/<marketplace>/<plugin>/<version>/` ([Plugin security](https://code.claude.com/docs/en/plugins/security)). Для автоматической проверки есть `uvx snyk-agent-scan@latest ~/.claude/skills` (нужен `SNYK_TOKEN`). Запускайте его в одноразовом окружении: «Scanning MCP configurations can execute commands» ([snyk/agent-scan](https://github.com/snyk/agent-scan)). Закрепляйте версии (`owner/repo#tag`, `pkg@x.y.z`) и держите автообновление выключенным у сторонних маркетплейсов. Звёзды не говорят о качестве: у ui-ux-pro-max 137,5k★, у superpowers около 302k★, а независимых оценок нет ни у одного дизайн-скила.

Правила запрещения и песочница работают так. Правила разрешений проверяются в порядке deny → ask → allow, и deny на любом уровне побеждает allow на любом уровне ([Permissions](https://code.claude.com/docs/en/permissions)). Песочница по умолчанию выключена. Включается она через `/sandbox` и на Linux использует `bubblewrap` и `socat`. Чтобы одна граница охватывала и процессы плагинов, запускайте сам Claude Code в контейнере или VM ([Sandboxing](https://code.claude.com/docs/en/sandboxing)). Пример базовой защиты в `.claude/settings.json`; синтаксис правил взят из документации, а состав — рекомендация:

```json
{
  "permissions": {
    "deny": ["Read(./.env)", "Read(./secrets/**)", "Bash(git push *)"],
    "ask": ["mcp__blender__execute_blender_code"]
  }
}
```

Для визуальных областей есть свои риски. Почти все DCC-мосты открывают сокет без аутентификации: Blender и Fusion на `localhost:9876`, официальный Unreal MCP на `127.0.0.1:8000`. Держите их на localhost, для удалённой машины используйте SSH-туннель, и, как пишут авторы Fusion-сервера, «never bind to 0.0.0.0» ([mcp-for-blender](https://github.com/ahujasid/mcp-for-blender#limitations--security-considerations); [fusion360-mcp-server](https://github.com/faust-machines/fusion360-mcp-server)). Не разрешайте `execute_blender_code` заранее и глобально. Безопаснее включить `BLENDER_MCP_SAFE_MODE=1`, который блокирует файловый I/O, процессы и сеть, но оставляет моделирование и рендер, и сохранить `.blend` перед сессией ([README](https://github.com/ahujasid/mcp-for-blender#limitations--security-considerations)). Браузерные MCP читают живой веб, а это главный путь для prompt injection. Направляйте их на локальный dev-сервер или в изолированный профиль. Режим Playwright `--extension` использует ваши залогиненные сессии ([Playwright MCP](https://github.com/microsoft/playwright-mcp/blob/main/README.md)). Телеметрию собирают несколько инструментов. Chrome DevTools MCP шлёт статистику, а трассы уходят в CrUX; отключается флагами `--no-usage-statistics` и `--no-performance-crux`. MCP for Blender отключается через `DISABLE_TELEMETRY=true`, CLI `npx skills` — через `DISABLE_TELEMETRY` или `DO_NOT_TRACK`. Модули Modern Web Guidance, Vercel и Premiere MCP тоже собирают телеметрию ([Chrome DevTools MCP](https://github.com/ChromeDevTools/chrome-devtools-mcp); [mcp-for-blender](https://github.com/ahujasid/mcp-for-blender#telemetry-control); [vercel-labs/skills](https://github.com/vercel-labs/skills)). Установщики вида `curl … | sh` (MCP for Blender, Google Genmedia, D2) сначала скачайте и прочитайте, а потом запускайте.

## Выводы

Во всех четырёх областях работает одно правило: выигрывает не тот набор, где больше скилов, а тот, где замкнут визуальный цикл и где инструмент поддерживает вендор самого продукта. MCP в 2026 году отступает туда, где действительно есть живое состояние: файл Figma, сцена Blender, таймлайн Resolve, редактор Unity. Знания и всё, что можно сделать командой, переезжает в связку «скил + CLI». Remotion закрыл MCP, Microsoft советует playwright-cli, next-devtools превратил инструменты в скилы, Context7 работает без MCP. При выборе инструмента полезно спросить себя: нужно ли Claude живое состояние внешней программы? Если нет, скил плюс CLI почти всегда дешевле по контексту и надёжнее в вызове.

Вторая находка — экосистема очень хрупкая, и относиться к ней стоит как к зависимостям проекта, а не как к настройкам. За год переименованы blender-mcp, Magic MCP, mcp-video, CapCutAPI и d2. Объявлены устаревшими или заархивированы Remotion MCP, локальные серверы Recraft и ElevenLabs и Runway MCP. Платные барьеры появляются внезапно: Resolve Studio, место Dev в Figma, Company License в Remotion, Meshy Pro, Unity AI. Многие самые популярные репозитории младше двух месяцев. Независимых бенчмарков качества дизайн-скилов нет. Единственные жёсткие цифры — вендорские evals (Modern Web Guidance +28 п. п., build123d на CADGenBench). Поэтому закрепляйте версии, раз в квартал пересматривайте набор и проверяйте каждый скил собственным A/B-прогоном через `skillOverrides`, а не по числу звёзд.
